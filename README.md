# Accounting Playground

## ACCT 2102 财报实验室

一个单文件网页，配合 HKU ACCT 2102（Intermediate Accounting I，IFRS）第 1–4 章学习。录入交易后，它会自动生成整个会计循环：日记账、T 字账、试算平衡工作底稿、损益及其他综合收益表、权益变动表、财务状况表、现金流量表和结账分录。

### 功能

- **两种使用场景**：「学习账本」保留课程示例、分录解释和练习；「财务记录」从空账本开始，自动计税默认关闭。两个账本分别保存，查看示例或练习题不会覆盖财务记录。
- **更快录入**：服务收入、日常支出、客户还款、支付欠款有常用入口，全部模板支持搜索。可填写往来对象和单据编号，复制已有交易为草稿；按 Ctrl/⌘ + Enter 记账。
- **自定义费用名称**：「日常支出」直接填写交通费、办公用品、软件订阅费等名称，无需选择预设费用类型。名称会保留在分录、搜索和 CSV 中；损益表切换到「按性质」会按名称汇总。租金、水电等常见名称沿用对应费用科目，其他自定义名称记入其他营业费用。
- **查找与导出**：按摘要、往来对象、单据、科目及日期范围查找分录，查看匹配记录的收现、付现和净现金变动，并导出 Excel 可读的 CSV。筛选只影响分录列表和 CSV，财务报表仍汇总全年数据。
- **学习指引**：提供「看分录解释 → 看报表来源 → 做练习题」入口、借贷速查表和逐行解释，保留报表自测。
- **数据保护**：未记账的模板和自定义分录自动保存为草稿，刷新后恢复。显示保存状态和失败提示；导入前校验并预览，覆盖前保存一份可恢复副本。录入日期必须属于当前会计年度。
- **34 种交易模板**：日常经营、投资、筹资、期末调整、OCI、终止经营。也可以自己写分录。
- **追溯数字来源**：点报表上的任何数字，可以看到计算公式和构成它的分录。点一笔交易，会高亮它影响到的每一行，一路到净利润、留存收益和现金。
- **切换列报方式**：费用按功能 / 按性质，单一报表 / 两张报表，现金流量表直接法 / 间接法。
- **勾稽检查**：借贷平衡、资产 = 负债 + 权益、净利润 → 留存收益、现金流量表与财务状况表的现金一致、直接法 = 间接法。
- **练习模式**：隐藏分录，报表数字留空自测。
- **36 道练习题**：覆盖第 1–4 章，有选择、配对、计算和分录题，提交后自动判分并给出详解。其中 6 道计算题可以一键载入工作台验证。

### 使用

用浏览器直接打开 `index.html`，不需要安装任何东西。

- 数据和作答记录保存在浏览器的 localStorage 里。换电脑或清除浏览数据前，用右上角「备份」导出 JSON。
- JSON 备份包含当前所选账本的公司设置、期初余额和交易。两个账本需分别备份；练习作答、未记账草稿和覆盖前的恢复副本只保存在当前浏览器。
- 在「备份 / 恢复」中选择文件或粘贴 JSON，先查看导入预览，再确认替换。新建空账本和重载示例同样先预览；可在此处恢复上次覆盖前的账本。
- 本页沿用课程的 IFRS 科目和全年会计循环。财务记录以此科目表生成报表；有额外科目或税务口径要求时，应自行核对。每个场景保存一份当前年度的账本，开始新年度前先备份。
- 「AI 描述」录入和「让 Claude 出新题」只在 Claude 里打开时可用，单独打开网页时会自动隐藏。

示例公司和题目中的公司都是虚构的，仅供学习使用。
